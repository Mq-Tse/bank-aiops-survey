# GitHub 银行 AI Ops 开源项目调研平台 - 验证清单

## 数据完整性验证
- [ ] 项目数据源包含至少 12 个开源项目条目
- [ ] 项目覆盖 5 大分类：可观测性平台、告警管理、日志分析、AI 智能体、流程编排
- [ ] 每个项目条目包含所有必要字段（name, url, stars, license, stack, features, category, bankValue, maturity）
- [ ] 每个项目标注了银行应用价值和成熟度评分

## 信息准确性验证
- [ ] 所有项目的 GitHub 链接可正常访问
- [ ] 项目名称与 GitHub 仓库名称一致
- [ ] Stars 数与 GitHub 实际数据偏差在 ±10% 以内
- [ ] 许可证类型标注准确（MIT、Apache-2.0、GPL-3.0、AGPL-3.0 等）
- [ ] 技术栈标注正确（Go、Python、Java、TypeScript、Rust、C 等）

## 功能展示验证
- [ ] 项目卡片列表展示所有项目，无遗漏
- [ ] 分类筛选器至少包含 6 个分类选项且功能正常
- [ ] 排序功能（按 Stars、成熟度）工作正常
- [ ] 搜索功能支持按名称、技术栈、关键词检索
- [ ] 项目详情弹窗/展开显示完整信息
- [ ] 多维度对比表格包含至少 10 个对比维度
- [ ] 对比表格支持多选项目横向对比
- [ ] 对比表格支持按任意列排序

## 选型建议验证
- [ ] 选型建议覆盖 5 个核心技术分层：基础可观测性、告警管理、AI 智能体、金融流程编排、日志分析
- [ ] 每个场景至少给出 1 个推荐项目并附理由
- [ ] 选型建议考虑了银行安全合规要求
- [ ] 选型建议包含国内银行特殊考虑（国产化、中文支持、离线部署）

## 趋势分析验证
- [ ] 趋势分析覆盖至少 3 个技术方向（eBPF、AI Agent、开源标准治理）
- [ ] 每个趋势方向有具体项目案例支撑
- [ ] 每个趋势方向说明对银行的落地价值

## 整体体验验证
- [ ] 页面结构清晰，信息层次分明
- [ ] 中英文术语使用一致且正确
- [ ] 响应式设计在不同屏幕尺寸下正常显示
- [ ] 视觉风格统一，配色合理
